# Contenido de Echo

Aquí va el contenido real de Echo (módulos, cursos, lecciones, actividades, casos, exámenes e insignias) y las
versiones de los documentos legales. El formato y cómo se carga están en `docs/backend/contenido.md`.

Para revisar y cargar, desde `backend/`:

```bash
npm run contenido:revisar
npm run contenido:cargar
```

La semilla de desarrollo (contenido de ejemplo) no vive aquí: está en `backend/prisma/semilla/` y se carga con
`npm run bd:reiniciar`.
